# Ajustes de consolas visibles

Tirsolador incluirá una sección en **Ajustes > Consolas visibles**.

## Funciones

- Mostrar u ocultar cada consola individualmente.
- Aplicar cambios sin reiniciar la aplicación.
- Restaurar la configuración predeterminada.
- Ocultar consolas que todavía no tengan canales configurados.
- Mantener la selección guardada por perfil local.
- Conservar los juegos y partidas aunque una consola esté temporalmente oculta.
- Mostrar una advertencia antes de ocultar la última consola visible.

## Consolas configurables

- NES
- SNES
- Sega Mega Drive
- Game Boy
- Game Boy Color
- Game Boy Advance
- Nintendo 64
- MAME
- Nintendo DS

## Comportamiento

Una consola oculta desaparece de:

- La pantalla principal.
- La navegación entre consolas.
- Los filtros generales de biblioteca.

La consola seguirá disponible en Ajustes para volver a activarla. Los juegos descargados, favoritos, metadatos y partidas no se eliminan al ocultarla.

## Navegación con mando

- D-pad arriba/abajo: cambiar de consola.
- A/Enter: activar o desactivar.
- B/Back: regresar.
- Long press de A/Enter: abrir opciones de la consola, si existen.

La configuración debe almacenarse localmente y quedar preparada para sincronizarse por perfil en una futura versión.
